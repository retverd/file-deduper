```markdown
# file-deduper

```

## Реализация
- Скрипт будет использовать только стандартную библиотеку Python 3.12: `argparse`, `hashlib`, `logging`, `pathlib`, `collections` и `sys`.
- CLI будет принимать один обязательный аргумент: путь к папке.
- Для каждого обычного файла внутри папки и всех подпапок скрипт посчитает `SHA-256` потоковым чтением блоками, чтобы не загружать большие файлы целиком в память.
- Будет храниться отображение `checksum -> list[Path]` с полными абсолютными путями.
- Для вывода использовать настроенный `logging.Logger` с двумя обработчиками: консольным и файловым.
- Log-файл будет создаваться кроссплатформенно через `pathlib` в папке `logs/` в корне запуска скрипта.
- Имя log-файла будет иметь вид `exec-<timestamp>.log`, где timestamp содержит подчеркивания между группами даты и времени, например `exec-2026_05_19-23_06_00.log`.
- Папка `logs/` будет создаваться автоматически при запуске скрипта.
- Первой строкой log-файла будет полный абсолютный путь к проверяемой папке.
- В конце скрипт залогирует только те группы, где у одной контрольной суммы больше одного файла. Если дубликаты не найдены, залогирует понятное сообщение.
- Реализация будет совместима с Windows и Linux: без жестко заданных разделителей путей, shell-команд и платформенных зависимостей.
- Добавить русские docstring к модулю и функциям, включая функции для настройки логгера, расчета хеша, обхода файлов, поиска дубликатов и точки входа.
