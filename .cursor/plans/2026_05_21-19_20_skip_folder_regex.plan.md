# План: Пропуск Папок По Regex

## Изменения
- В [`file_utils.py`](file_utils.py) заменить текущий `Path.rglob("*")` на управляемый обход через `Path.walk()` или эквивалентный рекурсивный обход, чтобы можно было удалять совпавшие имена папок из списка обхода до захода внутрь.
- Расширить `iter_files(folder, skip_dir_name_pattern=None)` так, чтобы он принимал уже скомпилированный `re.Pattern[str] | None` и пропускал директории, если `pattern.search(dir_name)` совпал.
- В [`folder_compare.py`](folder_compare.py) добавить необязательный именованный аргумент CLI, например `--skip-dir-name-regex`, с описанием на русском, скомпилировать его через `re.compile()` после парсинга и передать в `index_folder(...)` для обеих сравниваемых папок.
- В [`file_deduper.py`](file_deduper.py) добавить тот же флаг и передать скомпилированный regex в `find_duplicates(...)`.
- Обработать невалидное регулярное выражение через ошибку argparse, чтобы пользователь получил понятное сообщение и утилита не падала traceback'ом.
- Обновить [`README.md`](README.md): добавить примеры использования флага для поиска дубликатов и сравнения папок.

## Поведение
- Без нового флага обе утилиты работают как сейчас.
- Regex применяется к имени папки, а не к полному пути. Например, `--skip-dir-name-regex "^(node_modules|\.git)$"` пропустит папки `node_modules` и `.git` на любом уровне.
- Если имя папки совпало с regex, все её поддерево не обходится и файлы внутри не анализируются.

## Проверка
- Запустить help для обеих утилит: `python file_deduper.py --help` и `python folder_compare.py --help`.
- Сделать минимальную ручную проверку на временной структуре папок: убедиться, что файлы внутри совпавшей папки не попадают в анализ, а без флага попадают.
