# План изменения вывода дубликатов

Изменение затрагивает только [`file_deduper.py`](file_deduper.py), функцию `log_duplicates()`.

Сейчас каждая группа выводит полный путь и сортирует элементы по полному пути:

```python
for path in sorted(paths):
    logger.info("  %s", path)
```

План:

- Заменить сортировку внутри группы на сортировку по имени файла: `path.name.casefold()`.
- Добавить вторичный ключ по папке: `str(path.parent).casefold()`, чтобы порядок был стабильным, если имена одинаковые.
- Изменить строку вывода на формат `  <имя файла> | <папка>`, например `  report.pdf | C:\Files\Archive`.
- Оставить сортировку самих групп по контрольной сумме без изменений.
- Проверить запуск скрипта на синтаксические ошибки и при возможности выполнить быстрый прогон на тестовой папке с дубликатами.
