# План: размеры дубликатов и итог

## Что изменится
- В [`file_deduper.py`](file_deduper.py) добавить helper для человекоудобного форматирования байтов, например `512 B`, `1.5 KB`, `2.0 MB`.
- Обновить `log_duplicates()` так, чтобы каждая строка дубликата выводилась в формате:

```text
  report.pdf | 1.2 MB | C:\Users\user\Documents
```

- В конце вывода, перед строкой `Log-файл: ...`, добавить итог:

```text
Можно освободить до <size> места!
```

- Считать `<size>` как объем лишних копий: для каждой группы одинакового содержимого учитывать `размер файла * (количество файлов в группе - 1)`, потому что один экземпляр обычно нужно оставить.
- Обновить docstring в [`file_deduper.py`](file_deduper.py) и пример/описание формата в [`README.md`](README.md).

## Проверка
- Запустить скрипт на небольшой тестовой папке с дубликатами и убедиться, что:
  - размер появляется между именем и путем;
  - итоговая строка соответствует сумме удаляемых лишних копий;
  - README описывает актуальный формат.
