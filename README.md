# file-deduper

Простая консольная утилита, выводящая список файлов с одинаковым содержимым.

## Требования

- Python 3.12
- Windows или Linux

## Использование

Запустите скрипт и передайте путь к папке, которую нужно проверить:

```bash
python file_deduper.py /path/to/folder
```

На Windows путь можно передать так:

```powershell
python file_deduper.py "C:\Users\user\Documents"
```

Скрипт рекурсивно обходит указанную папку и все ее подпапки, считает контрольную сумму SHA-256 для каждого файла и выводит только те группы, где одинаковая контрольная сумма найдена более чем у одного файла.

В каждой группе сначала выводится имя файла, затем папка, где он находится:

```text
Контрольная сумма: <sha-256>
  report.pdf | C:\Users\user\Documents
  report.pdf | C:\Users\user\Downloads
```

Файлы внутри одной контрольной суммы сортируются по имени файла, а затем по папке, чтобы одинаковые имена шли подряд.

## Логи

Результат выводится одновременно в консоль и в log-файл. При каждом запуске создается новый файл в папке `logs`:

```text
logs/exec-YYYY_MM_DD-HH_MM_SS.log
```

Например:

```text
logs/exec-2026_05_19-23_06_00.log
```

Первая строка log-файла содержит полный путь к проверяемой папке. Папка `logs` создается автоматически и исключена из репозитория через `.gitignore`.
