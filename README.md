# file-deduper

Простые консольные утилиты для поиска файлов с одинаковым содержимым и
сравнения двух папок по содержимому.

## Требования

- Python 3.12
- Windows или Linux

## Поиск дубликатов

Запустите `file_deduper.py` и передайте путь к папке, которую нужно проверить:

```bash
python file_deduper.py /path/to/folder
```

На Windows путь можно передать так:

```powershell
python file_deduper.py "C:\Users\user\Documents"
```

Скрипт рекурсивно обходит указанную папку и все ее подпапки, считает контрольную сумму SHA-256 для каждого файла и выводит только те группы, где одинаковая контрольная сумма найдена более чем у одного файла.

В каждой группе сначала выводится имя файла, затем его размер в человекоудобном формате, а после этого папка, где он находится:

```text
Контрольная сумма: <sha-256>
  report.pdf | 1.2 MB | C:\Users\user\Documents
  report.pdf | 1.2 MB | C:\Users\user\Downloads

Можно освободить до 1.2 MB места!
```

Файлы внутри одной контрольной суммы сортируются по имени файла, а затем по папке, чтобы одинаковые имена шли подряд. Итоговая строка показывает размер лишних копий: для каждой группы считается, сколько места можно освободить, если оставить один экземпляр файла.

## Сравнение двух папок

Запустите `folder_compare.py` и передайте два пути к папкам:

```bash
python folder_compare.py /path/to/first /path/to/second
```

На Windows пути можно передать так:

```powershell
python folder_compare.py "C:\Users\user\Documents\A" "C:\Users\user\Documents\B"
```

Скрипт рекурсивно обходит обе папки со всеми вложенными подпапками, считает SHA-256 для каждого файла и сравнивает контрольные суммы, относительные пути и имена файлов. Относительные пути считаются от переданных корневых папок. Размер файла не участвует в сравнении и выводится только для справки.

Если содержимое папок полностью совпадает, выводится только вердикт:

```text
Содержимое папок полностью совпадает.
Log-файл: C:\Users\user\Documents\logs\compare-2026_05_20-23_10_00.log
```

Если есть различия, выводятся отдельные блоки:

```text
Содержимое папок отличается.

Файлы с одинаковым содержимым, но отличающимися именами или путями:

Контрольная сумма: <sha-256>
  A:
    report_old.pdf | 1.2 MB | docs\report_old.pdf
  B:
    report.pdf | 1.2 MB | docs\report.pdf

Файлы, которые есть только в папке "A":
  notes.txt | 512 B | notes.txt

Файлы, которые есть только в папке "B":
  photo.jpg | 2.4 MB | images\photo.jpg
```

Блок с одинаковым содержимым показывает файлы, у которых SHA-256 есть в обеих папках, но отличаются имя или относительный путь. Вместо обозначений "первая папка" и "вторая папка" в выводе используются имена переданных папок. Этот блок сортируется по контрольной сумме, имени файла и относительному пути. Блоки файлов только в одной папке включают файлы, SHA-256 которых отсутствует в другой папке, и сортируются по относительному пути и имени файла.

## Логи

Результат выводится одновременно в консоль и в log-файл. При каждом запуске создается новый файл в папке `logs`:

```text
logs/exec-YYYY_MM_DD-HH_MM_SS.log
logs/compare-YYYY_MM_DD-HH_MM_SS.log
```

Например:

```text
logs/exec-2026_05_19-23_06_00.log
```

Для `file_deduper.py` первая строка log-файла содержит полный путь к проверяемой папке. Для `folder_compare.py` первые строки содержат имена и пути к обеим сравниваемым папкам. Папка `logs` создается автоматически и исключена из репозитория через `.gitignore`.
